# 全网舆情与风评研判工作流（Yuqing Research · Verifiable Edition）

核心定位：**先清洗软文与水军噪音 → 再按信源血统分层与海内外双盘统计 → 用四象限呈现真实民间评论分布 → 用 SQLite 事件库持久化时间戳与反转链条。**

> **按需参考目录**：
> - `references/methodology.md`：弹幕峰值检测、Jaccard 3-Gram 水军去噪与楼中楼争议反转系数数学模型
> - `../../quick-research/references/review_gate.md`：独立审核闸门（G1–G5）

---

## 一、适用边界与采样档位选择

- **严格不越界**：要买哪款/比价 → 转 `shopping-research`；技术排错/架构对比 → 转 `quick-research`；只读单个新闻网页 → 直接摘要。
- **采样前先定档位**（用户未指定范围时一次确认）：
  1. `➡️ 推荐` **标准跨区大盘档**：国内主流平台 + 海外论坛联动，对比内外舆论温差；
  2. **国内聚焦档**：聚焦本地核心内容与长评社区，不做海外对照；
  3. **极速摸底档**：快速锁定头部热帖与前排高赞讨论，必须在交付时注明覆盖受限；
  4. **深度穿透档**：头部样本 + 腰部避坑长文 + 评论区深层反驳楼层 + 控评矩阵清洗。

## 二、核心清洗与研判五支柱

1. **信源血统分层（Lineage Profiling）**：
   - 将采集样本明确归类为三层：**官方/机构媒体 (`official`)**、**创作者/KOL 自媒体 (`creator`)**、**普通散户/真实用户 (`grassroots`)**；
   - 在顶部看板如实报告官媒与创作者占比，防止拿“媒体通稿刷屏”当成“大众真实心声”。
2. **海内外双沙盒独立统计**：
   - 中文社区与海外社区（`domestic` vs `international`）各自计算样本数与立场比例，**严禁混合加权**导致小众海外样本被吞没或放大。
3. **软文与水军两级清洗**：
   - 按商业特征（促销话术、导购短链、CTA 号召共现）对疑似推广内容打分剔除或移入「疑似投放待核清单」（引用时必须带「疑似」标注）；
   - 按 `references/methodology.md` 使用 **字符 3-Gram Jaccard 相似度（阈值 ≥0.80 且跨不同账号形成 ≥3 条模板簇）** 识别控评水军刷屏，剔除出真实口碑均值。
4. **事件中间层与四时间戳状态机**：
   - 对齐事件四时间戳：`observed_at`（首次观测）、`valid_from` / `valid_until`（生效窗）、`expired_at`（失效时点）；
   - 后续出现权威辟谣或核心反转时，对旧结论**追加标记 `superseded`** 而**绝不删除历史证据记录**，完整保留舆论演化轨迹；
   - 热度计算采用五维加权（量 20% + 跨源 20% + 跨轮 15% + 质量 30% + 新鲜度 15%）；若部分渠道未返回播放/点赞数，**必须保持为 `0` 或 `unknown`，严禁估算编造假热度**；若仅凭语音转写未人工听核的片段，强制标注 `asr_unverified` 并提示引前复核原视频。
5. **事件历史与来源健康持久化（`tools/event_history_store.py`）**：
   - 使用 SQLite `EventHistoryStore` 的 `commit_run()` 在单事务内原子写入原始事件（自动计算 `content_hash` / `payload_hash`）、`source_health` 健康状态与投递台账，并支持兼容旧版 JSON 原子导出。

## 三、真实评论四象限与五段式标准输出

将筛选后的高讨论度/高争议系数评论拆为四个象限呈现：
1. **激进声讨与行动派**（明确抵制、退货、维权或强硬批评）；
2. **理性剖析与归因派**（就事论事拆解产品缺陷、供应链或管理原因）；
3. **结构反思与深层对账派**（跳出单一事件看行业潜规则、定价逻辑或制度根源）；
4. **戏谑解构与乐子人派**（玩梗、反讽与传播二创，往往反映真实情绪泄压口）。

报告固定五段式交付结构：
1. **顶置执行遥测与质检看板**（总样本量、去噪水军/软文剔除数、信源血统分布、逐源成功/超时/受阻原样状态）；
2. **核心大盘速览**（一句话定调 + 海内外温差对比）；
3. **四象限真实评论原声展台**（每象限配真实占比 + 1~2 条带点赞数与 `[SRC-xxx]` 原话）；
4. **软文与水军清洗及事件反转对账**（严格对齐清洗前后数字，不夸大不隐瞒）；
5. **确定性核验与交付前自审**：
   - 运行 `python tools/citation_audit.py` 与 `python tools/review_check.py --strict`；
   - 确保全程**零用户地域属地信息**，末尾输出 `### ✅ 交付前自审` 并建议高敏感话题另行在独立上下文按 `review_gate.md` 复核。
