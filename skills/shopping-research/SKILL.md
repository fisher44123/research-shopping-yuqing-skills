# 消费品循证选购调研工作流（Shopping Research · Verifiable Edition）

核心定位：**先认清商品的化学/物理真身 → 再把无品牌搜寻关键词摊开请用户确认 → 再用确定性脚本卡死同款 SKU 与单次使用成本 → 最后给可直接下单的清单与实操 SOP。**

> **按需参考目录**：
> - `references/design-notes.md`：经典选品范式与四维执行规范（审美 / 交互 / 逻辑 / 审计）
> - `../../quick-research/references/review_gate.md`：独立审核闸门（G1–G5 硬门禁）

---

## 一、开搜前品类认知校准（不先搜，先讲透三件事）

1. **它到底是什么（真身与国标）**：明确核心化学成分、物理结构或国家执行标准号，拆穿纯营销包装名称；
2. **哪些场景物理上无效（A 类真需求 vs B 类伪需求）**：直接划清适用边界与禁用材质，先帮用户排除无效诉求；
3. **性价比硬指标怎么算**：在第一屏约定唯一排序口径（消耗品用**单次使用成本**，耐用品用**持有周期日均成本** + 核心硬参数）。

---

## 二、三层双停顿节奏（严格按序，不得偷跑跳步）

每次停顿都给编号选项与明确 `➡️推荐默认项`，把用户确认成本压到极低。

- **L1 大盘摸底（第 1 轮检索）**：
  - 查品类主流流派、执行标准、真假分水岭与典型翻车坑；
  - 输出**五维需求激活卡**（身材工效 / 材料物理 / 机能协议 / 履约试错 / 二手残值，逐项显式标出开或关）+ 流派对比 + A/B 需求分层。
  - **🛑 停顿点 1（强制停顿）**：明文列出第二层拟执行的 **无品牌关键词矩阵（8~12 条，分为认知 / 实测效果 / 性价比三层）**，等用户确认或增删后再开搜；即使用户一开始说“直接给我推荐”，也必须先亮出矩阵确认一次。
- **L2 横评与红黑榜（第 2 轮检索）**：
  - 按已确认的无品牌矩阵打包通过 BYOT 搜索/MCP 通道取证（多批编号分开记如 `SRC-L2A-001`、`SRC-L2B-001` 避免撞号）；
  - 输出红黑榜（黑榜必须写具体翻车现象与失效原因）、测评对账摘要与 **3 款决赛圈候选**。
  - **🛑 停顿点 2（强制停顿）**：亮出 3 款候选及待爆破的疑点（真实到手价、包装规格陷阱、长期差评），**等用户选定后才可推进 L3，严禁提前偷跑 L3 检索**。
- **L3 实价爆破与 SKU 确定性对齐**：
  - 采集实价快照（未取到页面实价时保留候选并标注 `status=unpriced`，绝不直接淘汰为不合格；多渠道实价标明日期并列展示）；
  - 调用 `tools/sku_check.py` 做字段级比对并计算单位成本，坚决防止把「标准版 / 套件 / 上一代」低价安到「Pro / 成品 / 新款」头上。

```bash
# 商品实体字段对齐 + 复合规格折算 + 单次使用成本（出现不同型号即退出码 3）
python tools/sku_check.py \
  --target "目标商品完整标题（含品牌/型号/版本/容量/颜色）" \
  --cands-json candidates.json \
  --dose "25g" \
  --strict
```

## 三、成本公式与终稿五件套

```text
消耗品单次成本 = 真实到手价 ÷ (总净含量 ÷ 单次标准用量)
耐用品持有成本 = 真实到手价 ÷ 预计持有天数（如键盘/小家电常按 3 年 1,095 天计）
```

- **消耗品必填**：总净含量（支持自动折算 `500g*2袋` 等复合装）、采集日期与到手价、折合每 500g / 每 100ml 单价、**单次使用成本**及执行标准，对比句式：`贵的那款单次要 X 元，便宜这款 Y 元，差 N 倍。`
- **耐用品必填**：持有周期日均/年均成本 + 核心物理硬件规格（材质、结构、续航/功耗、售后质保），软件花哨生态权重严控封顶。

### 终稿五件套（缺一不可）
1. **🎯 一句话选购结论**（直接说买哪款、真实到手价、核心原因；如有检索受阻紧附健康提示）；
2. **📊 四列比价对账表**（严格 ≤4 列：候选与定位 ｜ 核心机理/硬参数 ｜ 到手价与单次/日均成本 ｜ 定性 🟢/🟡/🔴 与适用人群；别买踩坑款直接归入 🔴 行）；
3. **🧪 分场景定量 SOP**（按具体使用场景写清失效边界与 1~4 步定量操作，严禁出现“适量 / 酌情”等模糊词）；
4. **⚠️ 安全与防翻车铁律**（禁用材质清单、危险误操作后果、拆箱验真动作、囤货受潮或保质期风险）；
5. **📋 确定性核验与审计收尾**：
   - 全程事实与价格锚定 `[SRC-xxx]`，附 2 条精选五维原始证据；
   - 运行 `python tools/citation_audit.py` 与 `python tools/review_check.py --strict`；
   - 按 `review_gate.md` 对高客单价（如 ≥200 元）或复杂品类做数字与 SKU 独立抽核并输出 `### ✅ 交付前自审`。
